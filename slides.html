The app that fixes
its own bugs.

Regenesis runs a real hospital scheduling SaaS under a closed self-healing loop. Break it, and it detects, diagnoses, patches, and re-tests — learning a reusable skill every time. Its health is a heartbeat: sabotage is arrhythmia, healing is sinus rhythm.

how it works · a closed loop

QA is the selection pressure.

Three sponsor systems form one evolutionary loop around the product.

Replay · Loop QA

Detect

Autonomous exploration files real bugs — reproduction, root cause, screenshot chronology. The externally-judged fitness function.

Actian · VectorAI

Recall

"Have I seen this failure before?" Cosine search over proven fixes. Same defect → instant warm recall. New defect → first encounter.

Guild · Agent Hub

Evolve

The agent patches the rule genome, verifies, and publishes a versioned Skill. Next time, the skill activates instantly — it got faster.

The trick that makes it real: the app's rules are mutable (the genome), but the safety spec the oracle audits against is fixed. Sabotage weakens enforcement; the oracle can't be talked out of catching it. Every bug is genuinely detected — never scripted.

why it wins

One build. Three prizes.

Guild

An agent that authors its own versioned Skills on the Agent Hub and gets measurably faster each generation. Self-evolution in native Guild primitives — triggers, task state, skills.

Replay

A well-designed SaaS that QA's itself to zero open bugs. Completed QA with every bug fixed isn't a checkbox — it's the product's win condition.

Actian

VectorAI as agent memory: fixes stored as points, recall via cosine ANN with must/must-not filters and RRF hybrid search — exactly as documented.

Then we hand a judge the Sabotage button. They break the app; it heals in front of them. If it's seen the defect before — cosine 1.00, instant fix. That's the evolution, live.
